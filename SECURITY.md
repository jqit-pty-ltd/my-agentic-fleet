# Report a security problem

Thank you for helping to keep this project safe.

## Tell us in private

Please do not open a public issue for a security problem.

1. Open the **Security** tab of this repository.
2. Press **Report a vulnerability**.
3. Tell us what you found and how to see it happen.

You can also email **info@jqit.com.au**. Put "Security" in the subject line.

## What to send

- What you found.
- The steps to see it happen.
- What an attacker could do with it.

Do not send a real password, key or private file. A made-up example is enough.

## What happens next

We read every report. We tell you when we have read yours. We fix a real problem before we talk about it in public. We thank you by name if you want that.

## What this covers

This repository holds the home page only. The code is not here yet. A report about the home page, the licence files or the JQiT website is welcome now.
